CODES:

I investigated the application and comparative performance of machine-learning models for stroke prediction. I developed a systematic workflow involving missing-value imputation, categorical encoding, outlier detection and treatment using the IQR method, and class-imbalance correction with SMOTE. I subsequently trained, compared, and evaluated multiple predictive models using appropriate performance metrics, including hyperparameter tuning to improve model performance. This work strengthened my understanding of how data quality, preprocessing, class imbalance, model validation, and interpretability influence the reliability of predictive systems, particularly in healthcare applications.
